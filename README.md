
# 💈 Giovani Razor Barbearia

Landing page responsiva desenvolvida como projeto
demonstrativo de portfólio profissional.

O projeto apresenta uma identidade visual premium,
com tons de preto, grafite e dourado.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- CSS Grid
- Flexbox
- SVG
- Intersection Observer API

## ✨ Funcionalidades

- Layout responsivo
- Menu mobile interativo
- Galeria de imagens com Lightbox
- Animações cinematográficas
- Scroll Reveal
- Favicon personalizado
- Imagens otimizadas em WebP
- Links para Instagram e Google Maps

## 📌 Sobre o projeto

Desenvolvido com o objetivo de aprimorar conhecimentos
em desenvolvimento front-end, design responsivo,
acessibilidade e otimização de desempenho.

da barbearia. As fotografias são ilustrativas e foram
geradas por inteligência artificial.
